# Pedidos para o dia a dia

Os exemplos abaixo são sugestões de uso. Os resultados dependem do perfil, dos arquivos do projeto e das integrações que você disponibilizar.

## Pesquisa ligada ao seu trabalho

“Pesquise as mudanças recentes relevantes para as tecnologias do meu projeto. Priorize documentação oficial, informe a data de cada mudança e explique o impacto prático. Termine com três ações que fazem sentido para os meus objetivos.”

“Compare estas três ferramentas para o meu caso. Use meus critérios de decisão, confirme preços e limitações nas fontes oficiais e diga quais informações minhas ainda faltam para decidir.”

## Preparação para uma tarefa

“Leia a documentação deste projeto e explique o que preciso entender antes de implementar autenticação. Aponte os arquivos relevantes e as dúvidas que devem ser resolvidas.”

“Analise esta falha e proponha uma correção com uma forma de verificar o resultado.” Use a opção interativa se desejar que o Devin execute a correção.

## Conteúdo e aprendizado

“Considerando o público que registrei no perfil, pesquise três pautas úteis sobre Java e inteligência artificial. Mostre fontes primárias e explique o que cada pauta ensina.”

“Transforme esta ideia em um roteiro de aula. Antes, confira os fatos técnicos na documentação oficial e adapte a profundidade ao público do meu perfil.”

## Memórias explícitas

“Meu público é iniciante e prefere exemplos práticos” pode ser salvo como memória global.

“Neste projeto usamos Java 21 e Maven” deve ser salvo como memória do projeto.

Uma memória registrada aqui é incluída nos próximos pedidos aplicáveis. Isso não significa que os modelos foram treinados com ela.

## Quando houver conectores

“Prepare um briefing para a reunião com base na pauta e nos documentos que eu indicar. Separe fatos das hipóteses e mantenha os links para as fontes.”

“Identifique tarefas pendentes nesta lista e proponha a prioridade considerando meus objetivos.”

Os dois últimos exemplos precisam dos arquivos ou conectores correspondentes. O ZIP não concede acesso automático a agendas, mensagens ou contas.
